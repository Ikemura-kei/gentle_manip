# v3.3 synthesis — recipe + cluster handoff (2026-08-25)

Everything the cluster agent needs to run the v3.3 end-to-end experiment
(collect → filter → convert → co-train → eval). All code is on master
(collector: `grasp_synthesis/collect_demos_synth_v3.py`; every knob is a CLI flag,
defaults inert). Items 2+5 continuation; supersedes v3.2 (`bsipf`).

## What v3.3 is (diff vs the hwo foundation recipe)

| knob | hwo (afucm) | v3.3 | evidence |
|---|---|---|---|
| approach trajectory | straight lerp, fixed 77 steps | **continuous per-axis** (xy smoothstep finishing at f~U[0.45,0.75], z linear) + **per-env duration = profile arc-length / 0.0024 m/step** | real teleop: xy aligns at 60 % of pre-close still ~84 mm up; speed ~constant (corr(speed,dist) real 0.29 vs fixed-dur sim 0.91). v3.3 measured: speed band 2.42–2.55 mm/step (real median 2.37), hover-at-align 92–109 mm |
| settle before close | 1 | 1 (v3.2's 6 ROLLED BACK, user decision) | — |
| gripper close | 30 steps | **20 steps** | real closes in ~21 |
| grasp yaw / occlusion | unbounded | **azimuth ≤ 60°** of camera-perpendicular (shaped penalty + seed fan) | item 5; also pulls rotation to ~30° = real median |
| pose-diversity jitter | 20° | **30°** | user ask: more yaw/pitch/roll variety |
| trailing stop frames | 4 (trim 8/4) | **10** (trim 12/10) | fleli hold-deficit fix (4 frames = 1 action chunk of stop supervision; real carries 6) |
| anti-stem/pinch | none | **worst-pad area floor 15 mm²·scale² + pressure penalty 0.05** | stem grasp: min_pad 8 mm² / 114 kPa vs cap 49 mm² / 37 kPa. With knobs: min pad 3.6→17.7 mm², pressure p90 94→81 kPa, no stem grasps in visual check, success 100 % (16 eps) |
| post-filter | none | **pinch filter** (`gentle_manip/scripts/filter_pinch_episodes.py`) | drops dangling/rim grasps by TCP-vs-object geometry at hold (vert-primary criterion; ~2–5 % drop rate) |
| DR / meshes | single mushroom, scale [1.0,1.5] | **4-mesh pool × scale [0.8,1.5]** (`_mm4_s08`) | items 6+18 combined; per-mesh success 75–92 %, small scales 100 % (n=8) |

More CMA-ES iterations do NOT fix stem grasps — the FEM metric *prefers* them
(5.4 vs 10.0 kPa bulk stress); the area/pressure terms are what demote them.

## 1. Collect (the full recipe command)

```bash
uv run --project <sim env> python grasp_synthesis/collect_demos_synth_v3.py \
  --experiment single_lift_mushroom_soft_abs_action_armfocus_realws_mm4_s08 \
  --n-episodes 650 --n-envs 8 --scene-dr-every 1 --maxfevals 1145 \
  --n-home-to-pre 77 --n-grasp 20 --n-settle 1 --grasp-extra-close 0.005 \
  --cam-azimuth-max-deg 60 --grasp-jitter-deg 30 \
  --approach-xy-finish 0.45 0.75 --approach-speed 0.0024 \
  --held-run-max 12 --held-run-keep 10 \
  --grasp-area-min-mm2 15 --grasp-w-press 0.05 \
  --seed 0 --record-video 20
```
Expected demonstrator success ≈ 86–100 % (50-ep smoke: 86.2 %; 16-ep with anti-stem: 100 %).
`--n-home-to-pre` is only the fallback duration; `--approach-speed` overrides it per env
(durations land ~80–120 steps, episodes vary in length accordingly).

## 2. Pinch filter (BEFORE conversion)

```bash
uv run --project <sim env> python -m gentle_manip.scripts.filter_pinch_episodes \
  dataset/demos/single_lift_mushroom_soft/<run>
# -> <run>-filt/ with data.pkl + pinch_report.yaml; convert from <run>-filt
```

## 3. Convert + gates + merge (same as afucm/v31/v32)

```bash
uv run --project <dppo env> python -m gentle_manip.dppo.convert_demos <run>-filt \
  --out dataset/dppo/single_lift_mushroom_soft_v33_7d \
  --obs-keys ee_pos ee_quat gripper_width --point-cloud \
  --derive-action gentle_manip/configs/action/abs_pose_euler_abs_gripper.yaml \
  --derive-source-action gentle_manip/configs/action/abs_pose_abs_gripper.yaml
```
**Gates — two corrections to the historical checks:**
- Euler seam: diff **WITHIN episodes only** (use `traj_lengths`; concatenated diffs cross
  episode boundaries and false-trip on diverse end poses — v32 within-episode jump was
  0.016 = clean while the boundary jump read 1.131).
- Dwell: threshold **< 0.20** (the 10 stop frames push it up BY DESIGN; v32 measured 0.129.
  The real slice in the same mix carries 0.42 and works).

Merge with the real 55 (plain concat = noos), joint renorm:
```bash
uv run --project <dppo env> python -m gentle_manip.dppo.merge_npz_datasets \
  dataset/dppo/single_lift_mushroom_soft_v33_7d dataset/dppo/single_lift_mushroom_real \
  --out dataset/dppo/single_lift_mushroom_simreal_realws_noos_cmd_v33
```
(The merge drops sim-only aux arrays with a warning — expected.)

## 4. Train (afucm twin)

Big net (visual 512, mlp [1024]³), 600 epochs, save/100, batch 128, lr 1e-4, seed 42,
`experiment=single_lift_mushroom_soft_abs_action_armfocus_7d_realws`… i.e. exactly the
afucm setup with `env=single_lift_mushroom_simreal_realws_noos_cmd_v33`. A local cfg-dir
template: `gentle_manip/dppo/cfg/single_lift_mushroom_simreal_realws_noos_cmd_v32/`
(change `_v32`→`_v33`, n_epochs back to 600, save/100 for a full-size collection).

## 5. Eval

Canonical harness sweep of EVERY checkpoint; eval experiment
`single_lift_mushroom_soft_abs_action_armfocus_7d_realws` for the standard comparison —
plus optionally `..._mm4_s08`-based eval for the multi-mesh/size in-domain read (new
geometry; numbers not comparable to the baselines below). Best ckpt = best EVER success.

**Baselines to compare against** (local-protocol numbers, 200 eps / seed 42 / realws /
scene_group 4, all measured on the same local machine):

| run | best ckpt | success | ever | hold_gap | sustained | peak |
|---|---|---|---|---|---|---|
| afucm (foundation) | state_400 | 0.575 | 0.650 | 0.010 | 24.7 kPa | 50.9 kPa |
| fleli (v3.1) | state_200 | 0.265 | 0.610 | 0.035 | 30.1 kPa | 53.0 kPa |
| bsipf (v3.2, 191 demos, curtailed) | state_200/1200 | 0.055 | 0.140 | 0.035 | 16.0 kPa | 49.4 kPa |

Key watch item: **hold_failure_gap** — the 10-stop-frame fix should bring it to ~afucm's
0.010. Note cluster-protocol numbers (e.g. afucm 0.685) differ from local ones; compare
within one machine/protocol only.

## Known caveats

- Step-0 transient: the first ~3 commanded steps jump up to ~7 mm/step (home-offset DR vs
  nominal-home interpolation start) — pre-existing in every recipe incl. hwo; deploy warmup
  handles it.
- Kinematics vs real (50-ep smoke, filtered): speed 2.29/3.37 mm/step (real 2.20/3.67),
  rotation 29.9° (real 30.0), close 25 (real 21), xy_align 0.45 (real 0.60),
  hover-at-align ~109 mm (real 84, p90 148). Optional un-implemented refinement: per-env
  v_ref jitter (e.g. U[0.0020, 0.0028]) to reproduce the real ±20 % speed spread.
- `np.trapz` → `np.trapezoid` (NumPy 2) already fixed on master.
- Smoke datasets referenced here: `26-08-25-zrg` (50 ep, pre-anti-stem),
  `26-08-25-uix` (16 ep, speed verification), `26-08-25-vqg` (16 ep, full v3.3).
